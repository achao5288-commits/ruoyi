2. 启动文件问题分析

问题一: start_all.bat — 3 处硬编码路径错误

配置项脚本中的值实际路径状态
JAVA_HOME D:\jdk-25.0.2 C:\Program Files\Microsoft\jdk-25.0.4.101-hotspot 不存在
REDIS_CLI D:\Redis-8.6.3\redis-cli.exe C:\Program Files\Redis\redis-cli.exe 不存在
MySQL 密码 root 123456 错误
Profile all-local local (all-local 中密码也是 root) 不匹配
💡 修复方案: 修正 JAVA_HOME、REDIS_CLI 路径，MySQL 密码改为 123456，使用 local profile（默认配置正确）。

问题二: start.bat — 编码问题

无 BOM 的 UTF-8 编码
bat 文件路径包含中文 "实习"，在 cmd.exe (GBK 环境) 中执行时可能乱码，导致路径解析失败。
pnpm 命令在 cmd 中不可用
pnpm 仅在 TRAE VM 环境的 PowerShell 中可用 (pnpm.ps1)，普通 cmd 窗口可能找不到 pnpm 命令。
💡 修复方案: 将 start.bat 保存为 GBK 编码，或在 PowerShell 中执行。前端启动改用 npx vite。

问题三: application-all-local.yaml — 数据库密码不匹配

密码仍是 root
application-all-local.yaml 第 11 行: password: root，但实际 MySQL root 密码是 123456。已修改源码但未重新编译进 jar 包。
💡 修复方案: 使用 local profile（密码已正确为 123456），或重新编译时包含 all-local 配置。

问题四: Redis 版本过低

Redis 3.0.504 — 不兼容 IoT/消息总线
项目部分模块 (IoT、IM) 需要 Redis 5.0+。当前已注释这些模块所以不影响运行，但将来启用这些模块时必须升级。
💡 修复方案: 后续安装 Memurai (Redis 7 兼容 Windows) 或通过 WSL/Docker 运行 Redis 7。
